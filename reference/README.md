# 선별한 원본 코드

원본 코드를 통째로 복사하거나 Git 이력을 가져오지 않고, 설명에 필요한 핵심 함수·구간을 **정적 Markdown 코드 블록**으로 발췌했다. API·주문·shell 코드를 실행 파일로 배포하지 않기 위한 방식이다.

- [피처·학습·워크포워드·백테스트](ml-validation.md)
- [뉴스 중복 제거·LLM 요청·신호 판단](llm-news.md)
- [KIS 재시도·주문 경계·DB 동기화](api-state.md)
- [단계별 자동 실행](automation.md)
- [원본 파일·줄 범위·내용 해시](manifest.json)

발췌는 원본 그대로이며 일부 import·전역 상수·주변 문맥을 생략했다. 당시의 결함과 과장된 주석도 남아 있으므로 [구현 대조표](../docs/EVIDENCE.md)와 함께 읽는다. 특히 “5영업일”, “보수적”, “즉시”, “중복 방지” 등의 원본 주석을 검증된 결과로 해석하지 않는다.

직접 실행할 수 있는 코드는 `stock_ai_portfolio/`의 오프라인 재작성본이다. 새로 만든 입력 검증·상태 경고와 원래 존재했던 임계값을 [DEMO.md](../docs/DEMO.md)에 구분했다. 외부 라이브러리 소스·실제 기사·훈련 데이터·모델 가중치는 포함하지 않았다.
