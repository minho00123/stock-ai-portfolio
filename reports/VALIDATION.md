테스트는 신호의 경계값·중요도 가중 평균·뉴스 최소 수·시간대·미래 뉴스·시장 구분, 단일 대형 악재, 원본 주말 취소 조건 재현, pending·고아 상태 경고, 통계 산술, 입력 거부와 결정적 출력을 확인했다. 원본 프로젝트의 통합 테스트나 외부 서비스 정상 동작 검증이 아니다.

과거 학습·백테스트·워크포워드·브로커 성과 재조회는 실행하지 않았다. 학습 CSV·분기별 원시 결과가 없고 외부 호출 없이 확인할 수 있는 범위를 넘기 때문이다. 운영 모델 pickle은 로드하지 않았다. 초기 공개 검사에서는 발췌 코드 문자열 안의 백틱을 닫는 fence로 오인해 해시 불일치 1건이 보고됐다. 검사기의 fence 파서를 수정한 뒤 재검사해 통과했다. 단위 테스트는 실행한 두 차례 모두 27개가 통과했다. 미실행 검증을 성공으로 기록하지 않았다.

보안 검사는 알려진 값과 패턴에 대한 검사이며 완전한 비밀정보 탐지나 재배포 권리의 증명은 아니다. 소유·기여·라이선스·집계 공개 범위와 현재 자격증명 정리 상태는 [게시·검토 기록](../docs/PUBLICATION_REVIEW.md)에 남겼다. 초안 검증 후 사용자의 별도 게시 요청을 받아 새 포트폴리오 저장소를 게시한다. 원본 저장소의 공개 전환은 수행하지 않는다.

게시 직전 재검증에서도 단위 테스트 27개가 통과했다. 새로 생성된 Finder 메타데이터는 게시 폴더 밖으로 옮겼고, 공개 검사를 다시 통과했다. 검사기는 새 저장소의 `.git` 메타데이터를 공개 파일 검사에서 제외한다. 원본 Git 이력을 복사하지 않았는지는 새 저장소의 루트 커밋과 커밋 개수로 별도 확인한다.
