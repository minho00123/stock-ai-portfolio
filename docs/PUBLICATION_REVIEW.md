# 결과물과 공개 전 검토

## 분석한 실제 구현

원본 문서와 가격 피처·LightGBM 학습·미국/한국 매매·뉴스 수집·LLM 분석·신호 필터·비상매도·KIS 래퍼·백테스트·워크포워드·리포트·shell 실행을 대조했다. 회수된 SQLite DB 세 개는 읽기 전용으로 집계했고, 로그는 실행 기간과 실패 기록 존재를 확인했다. 모델 pickle은 로드하지 않았다. 정적 코드의 존재·문서상의 운영 결과·이번 실제 재집계를 구분했다.

## README 핵심 내용

지원자가 직접 정의한 목표·요구사항과 AI 협업 구현을 구분했다. 미국·한국 모의 시스템을 통합했으나 투자 우위는 입증하지 못했고, 상태 동기화·손익 기록의 한계와 부정적인 LLM 비상매도 결과를 확인한 뒤 실자금 투입 없이 종료했다. 구현 사실을 실패 없는 운영 실적이나 개인 단독 성과로 바꾸지 않았다.

| `analysis/`, 일회성 편입 스크립트 | 계좌 조회·기존 DB 변경 또는 특정 거래에 종속 |
| 원본 README·최종 검토·재개 문서 전체 | 접속·계정·다른 프로젝트·보안 운영 정보와 과거 계획 포함. 필요한 사실만 재서술 |
| 가상환경·외부 패키지·차트·화면 캡처 | 재현에 불필요. 시각 검증·스크린샷 생성은 하지 않음 |

## 보안 검사와 테스트

실행 결과는 [VALIDATION.md](../reports/VALIDATION.md)에 기록한다. 공개 후보의 패턴 검사 외에 원본 환경 파일의 비밀값과 알려진 식별값이 후보 파일에 그대로 복사됐는지 로컬에서 비출력 비교한다. 검사에는 원시 값을 로그로 남기지 않는다. 어떤 자동 검사도 미탐 가능성을 없애지는 못한다.

기존 문서에 자격증명 교체 미완료 기록이 있으므로 현재 교체 여부는 사용자 확인 항목이다. 이번 작업은 키 사용·검증·재발급을 수행하지 않았고 공개 후보에 키를 포함하지 않았다. 관련 접속 상세는 옮기지 않았다.

## 아직 확인이 필요한 사실

- 원본 원격 코드와 로컬 스냅샷의 일치 여부. 게시 단계에서 원본의 비공개 설정은 확인했으나 원격 코드는 대조하지 않음.
- 설계·운영·분석의 세부 역할 분담. 사용자 확인은 목표·요구사항 직접 정의와 코드 AI 협업까지이며 단계별 독자 수행을 증명하지 않음.
- 과거 분기별 검증 결과, 데이터 provenance, 수정 전후 성과. 원본 CSV가 없어 재현하지 못함.
- 당시 브로커 최종 집계와 원시 주문·체결의 완전한 대사, 고아 포지션별 원인, 한국 누락 손익.
- LLM을 쓰지 않았을 때의 대조 결과와 모델 변경 시점·비용. 현재 손실 집계만으로 인과 효과를 확정할 수 없음.
- 서버 작업별 성공률·현재 인프라 및 credential 정리 상태. 문서 종료 기록을 현재 상태 확인으로 바꾸지 않음.
- 코드·데이터·가중치 권리와 최종 라이선스. [권리 검토](DATA_AND_RIGHTS.md) 참조.
