# 데이터·라이브러리·모델 공개 검토

## 포함한 자료

| 자료 | 처리 | 남은 확인 |
|---|---|---|
| 합성 JSON | 이번에 새로 생성, 실제 뉴스·거래 행 없음 | 합성 표시 유지 |
| 모의 운영 요약 | 상태별 건수·손익 합계·모델별 분석 건수와 문서의 수익률만 포함 | 계좌 식별·건별 기록은 제외. 이 집계 수준 공개에 대한 사용자 최종 검토 |
| 핵심 코드 발췌 | API 비밀값 없이 자체 프로젝트 코드만 선택 | 원본 코드의 소유·제3자 코드 혼입 여부 확인 필요 |
| 오프라인 재작성본·테스트 | 표준 라이브러리만 사용 | 이번에 작성한 코드라는 출처 표시 유지 |

## 제외한 자료

실제 가격 CSV·뉴스 제목·요약·기사 URL·뉴스 DB는 배포하지 않는다. 데이터 제공자의 이용 조건과 뉴스 저작권·재배포 허용 여부를 확인하지 않았으므로, API에서 조회할 수 있다는 사실을 재배포 허가로 해석하지 않았다. 모의 운영 DB·로그 역시 식별·주문·보유 정보가 있어 제외했다.

기존 LightGBM pickle 두 개는 복사하거나 로드하지 않았다. 학습 데이터 재배포·학습 산출물 공개 가능 여부와 provenance를 확인하지 못했고, 공개 데모에 가중치가 필요하지 않다. 과거 학습 데이터가 로컬에 없어 학습·평가 결과를 다시 만들 수도 없다.

원본 `requirements.txt`는 분석했으나 새 패키지의 설치 목록으로 복사하지 않았다. 이 초안은 과거 시스템 전체를 설치·실행하는 패키지가 아니다. 외부 라이브러리 소스·wheel·가상환경·SDK를 동봉하지 않는다. 원본 고정 버전의 설치 가능성·지원 상태는 검증하지 않았다.

## 라이선스 판단

원본 최상위에 LICENSE 파일은 확인되지 않았다. 사용자가 자신의 프로젝트라고 설명한 사실만으로 외부 코드의 권리나 모든 AI 생성 코드의 재배포 조건까지 확정할 수는 없다. 따라서 임의로 MIT 등 포괄적 라이선스를 부여하지 않았다. 이번 작업에서는 법률 자문이나 외부 서비스 약관의 최신 상태 확인을 수행하지 않았다.

사용자의 게시 요청에 따라 공개하되, 별도의 LICENSE는 부여하지 않았다. 원본·참조 코드의 권리와 원하는 사용 허용 범위는 확인 과제로 남아 있다. 공개 저장소로 읽게 하는 것과 자유로운 재사용을 허락하는 것은 구분해서 결정한다.
